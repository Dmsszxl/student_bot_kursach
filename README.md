# Бот для первокурсников

Курсовой проект по созданию Telegram-бота для студентов первого курса. Бот помогает повторять материал по программированию и математике, разбирать примеры и проверять себя на коротких задачах.

## Учебные темы

| Раздел | Темы |
| --- | --- |
| Программирование | Ввод и вывод в C++, переменные и типы `int`, `double`, `char`, арифметика и остаток от деления, сравнения и условия `if/else`. |
| Математика → Алгебра и геометрия | Действия с комплексными числами, сопряжённое число и модуль, размеры матриц и простые операции, умножение матриц, координаты и длина вектора. |
| Математика → Математический анализ | Метод математической индукции, графики функций и сдвиги, пределы последовательностей, пределы функций и подстановка, неопределённость `0/0`. |

## Как проходит урок

После команды `/start` выбери предмет и тему. В каждой теме есть три кнопки:

- **Справка** — короткое объяснение основных правил.
- **Пример** — программа с разбором вывода или математическое доказательство по шагам.
- **Решить задачу** — задание для самостоятельной проверки. В большинстве тем ответ выбирается кнопкой. В задачах на пределы его нужно отправить сообщением, например `2`, `0,5` или `1/2`. При ошибке бот даёт подсказку и предлагает попробовать ещё раз.

Например, в задаче по C++ нужно определить, в каком порядке программа выведет два введённых числа. Если выбрать неверный ответ, бот предложит перечитать строку со `std::cout` и проверить, где печатается пробел.

## Помощь ИИ

- **Спросить ИИ** в главном меню открывает диалог, в котором можно написать свой вопрос, например «Почему в C++ для ввода используют `>>`, а для вывода `<<`?».
- **Объясни подробнее** появляется после неверного ответа в задаче. Groq даёт дополнительную подсказку. Под ней можно нажать **Задать вопрос по подсказке**, и бот передаст ИИ условие задачи и предыдущую подсказку.

Для уточнений бот учитывает последние три пары вопрос–ответ. При выходе из диалога его история сбрасывается.

## Структура проекта

Бот написан на Python с библиотекой `python-telegram-bot`. Для подключения к Groq используется SDK `openai`.

- `main.py` — запуск бота, главное меню и переходы между экранами.
- `cpp_lessons.py` и `math_lessons.py` — справки, примеры, задачи и варианты ответов.
- `lesson_pages.py` — из уроков и задач собирает экраны и кнопки.
- `ai_tutor.py` — запросы к Groq и контекст диалога.

## Локальный запуск

Получи токен у [@BotFather](https://t.me/BotFather) и добавь строку `BOT_TOKEN=твой_токен` в файл `.env` в папке проекта.

Для общения с ИИ добавь в тот же файл `GROQ_API_KEY=твой_ключ`. Задать вопрос можно из главного меню или после ИИ-подсказки в задаче. Кнопка «Выйти из ИИ» возвращает в главное меню. Справка, примеры и проверка ответов работают и без ключа Groq.

При первом запуске создай окружение и установи зависимости.

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

Для запуска из нового окна терминала выполни в папке проекта:

```bash
source venv/bin/activate
python main.py
```

В Telegram отправь боту `/start`. Для остановки нажми `Control+C` в терминале.
